OPCIÓN 1: Doble-clic en index.html
  1. Navega a: c:\Users\windows10\Downloads\Pagina web H4 procesual
  2. Haz doble-clic en: index.html
  3. ¡La página se abrirá automáticamente!

OPCIÓN 2: Servidor local (recomendado)
  Abre PowerShell en la carpeta y ejecuta:
  
  python -m http.server 8000
  
  Luego accede a: http://localhost:8000

🎯 QUÉ PROBAR PRIMERO
═══════════════════════════════════════════════════════════════════════════

1. Abre la página en tu navegador
   → Deberías ver un header turquesa con logo

2. Desplázate hacia abajo
   → Verás las secciones apareciendo con fade-in suave

3. Ve a "Arma tu Bowl"
   → Interactúa con los controles deslizantes

4. Selecciona:
   - Base: Quinua
   - Proteína: Paiche
   - Salsa: Sriracha
   - Vegetales: Mango y Palta
   → El resumen se actualiza automáticamente

5. El precio debe ser: S/. 10 + 15 + 1 + 2 + 2 = S/. 30.00

6. Haz clic en "Agregar al Carrito"
   → Aparecerá un alert confirmando

7. En móvil
   → Prueba el menú hamburguesa (click en ☰)

🛠️ PERSONALIZACIÓN RÁPIDA
═══════════════════════════════════════════════════════════════════════════

CAMBIAR PRECIOS:
  → Edita js/script.js (línea ~60)
  → Busca: this.precios = {
  → Cambia los valores

CAMBIAR COLORES:
  → Edita css/styles.css (línea ~10)
  → Busca: :root {
  → Cambia los valores de --primary-color, etc.

CAMBIAR INFORMACIÓN DE CONTACTO:
  → Edita index.html (línea ~280)
  → Busca: "Contacto" en el footer
  → Cambia teléfono, email, dirección

USAR IMÁGENES REALES:
  → Coloca tus imágenes en assets/img/
  → Cambia en index.html de .svg a .png o .jpg

💡 TIPS Y TRUCOS
═══════════════════════════════════════════════════════════════════════════

1. Abre DevTools (F12) para ver cualquier error
2. En mobile, prueba: F12 → Toggle device toolbar (Ctrl+Shift+M)
3. localStorage guarda el carrito (recarga para ver persistencia)
4. Los SVG se ven bien en cualquier tamaño
5. Sin dependencias externas = carga rápida
6. Scroll suave funciona en todos los navegadores modernos


🐛 SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════

"Las imágenes no se ven"
→ Usa un servidor local en lugar de abrir directamente

"El menú hamburguesa no funciona"
→ Recarga la página (F5)
→ Abre DevTools y verifica que no hay errores

"Los precios no se actualizan"
→ Recarga la página
→ Limpia el caché (Ctrl+Shift+Supr)

"Algo se ve roto en móvil"
→ Abre DevTools → Responsive mode
→ Selecciona un dispositivo móvil
→ Recarga la página
